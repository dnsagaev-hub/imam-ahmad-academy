# Академия имама Ахмада

Сайт онлайн-школы ханбалитского фикха: курсы с уроками и тестами, аудио- и видеоуроки,
статьи и разборы вопросов, библиотека, личный кабинет ученика и админка для наполнения.

**Технологии:** Next.js 16 + Payload CMS 3 (админка, регистрация, база) + PostgreSQL.

---

## Локальная версия на своём компьютере

1. Установите Docker Desktop (docker.com) и запустите его.
2. Распакуйте архив проекта и дважды щёлкните «Запустить сайт (Windows).bat» или «Запустить сайт (Mac).command».
3. Первый запуск занимает 5–10 минут. Затем откроется http://localhost:3000, админка — http://localhost:3000/admin
   (при первом входе создайте учётную запись администратора).
4. Остановить — «Остановить сайт». Данные (уроки, файлы) сохраняются между запусками.

## Что где находится

| Адрес на сайте | Что это |
| --- | --- |
| `/` | Главная |
| `/courses`, `/courses/<адрес>` | Список курсов и страница курса с программой |
| `/lessons/<адрес>` | Урок: видео/аудио, конспект, тест |
| `/text`, `/audio`, `/video` | Текстовые, аудио- и видеоуроки: рубрика → полка книг → уроки книги (`?book=<адрес книги>`) |
| `/prayer-times` | Время намазов (расчёт в браузере по геолокации или городу) |
| `/articles`, `/articles/<адрес>` | Статьи и разборы вопросов |
| `/library` | Библиотека (PDF) |
| `/quran`, `/quran/<номер>` | Коран: список 114 сур с поиском; сура — арабский текст и перевод, комментарии к аятам, «Слушать» |
| `/about`, `/contact` | О сайте, форма вопроса |
| `/progress` | «Мой прогресс» (когда регистрация выключена) |
| `/login`, `/register`, `/cabinet` | Вход, регистрация, личный кабинет (когда регистрация включена) |
| `/admin` | Админка (только для администраторов) |

Код: `src/collections` — что хранится в базе (курсы, уроки, тесты…), `src/app/(frontend)` — страницы сайта,
`src/components` — части страниц, `src/lib/learning.ts` — правила обучения (открытие уроков, уровни).

## Регистрация выключена (режим по умолчанию)

Пока переменная `NEXT_PUBLIC_REGISTRATION_ENABLED` не равна `true`, сайт **не собирает персональные данные**:

- нет регистрации, входа и формы «Задать вопрос» (вместо неё — ссылки на Telegram и почту из «Настроек сайта»);
- тесты работают, а прогресс, баллы и уровень хранятся **в браузере ученика** (страница `/progress` — «Мой прогресс»);
- прогресс можно сохранить в файл и загрузить на другом устройстве;
- порядок уроков проверяется в браузере — это помощь в обучении, а не защита;
- в админку `/admin` по-прежнему входит только администратор.

Чтобы включить регистрацию позже: подготовьте политику конфиденциальности и уведомление Роскомнадзора,
задайте `NEXT_PUBLIC_REGISTRATION_ENABLED=true` и пересоберите сайт. Появятся вход, регистрация, личный кабинет `/cabinet`
и форма вопросов; прогресс будет храниться на сервере.

## Как устроено обучение

- Курс состоит из **модулей**, модуль — из **уроков** (по порядку).
- Первый урок курса открыт всем. Следующий открывается, когда ученик **сдал тест** предыдущего
  (проходной балл задаётся в уроке, по умолчанию 70%).
- Верные ответы хранятся только на сервере и в браузер не попадают.
- Если у урока нет вопросов, ученик нажимает «Отметить пройденным».
- **Уровень ученика — по четырём ступеням программы:** Тамхиди (подготовительная, с начала) → Мубтади (начальная)
  → Мутавассит (средняя) → Мутакаддим (продвинутая). Следующая ступень присваивается, когда пройдены все курсы
  текущей ступени, в которых есть уроки, и средний балл тестов не ниже 80%. Если на ступени ещё нет курсов
  с уроками, дальше она не пускает. Правила — в `src/lib/learning.ts` (`studentLevel`).

## Дата, намазы, значок

- Вверху каждой страницы — дата по григорианскому календарю и по хиджре (Умм аль-Кура) и ближайший намаз.
- Время намазов считается **в браузере** по координатам (геолокация или выбор города) — местоположение
  никуда не отправляется. Аср — когда тень равна длине предмета (мнение ханбалитов).
  Город и метод по умолчанию, поправка даты хиджры (±2 дня) — в «Настройках сайта».
- Значок академии: `public/brand/` (эмблема, полный логотип), иконка сайта — `src/app/(frontend)/icon.png`.

## Как наполнять сайт (админка `/admin`)

1. **Обучение → Уроки → Создать.** Название, рубрика, ссылка на видео, MP3, **текст урока** (тогда урок появится
   в «Текстовых уроках»), конспект, вопросы теста.
   Для вопроса укажите варианты и **номер верного варианта** (1, 2, 3…).
   Справа поле **«Книга»**: по какой книге урок. В разделах уроков он появится под обложкой этой книги, а на странице
   книги в библиотеке — ссылка «Уроки по этой книге». Если поле пустое, а урок входит в курс, берётся первая книга
   курса («Учебники из библиотеки»). Урок без книги показывается в блоке «Другие уроки».
   Карту, схему или родословное древо вставьте в текст урока блоком **«Рисунок»**: картинка, подпись и источник.
   Картинка встанет ровно там, где блок, а по нажатию откроется крупно. Блок есть и в статьях.
   Хадис вставляйте блоком **«Хадис»**: арабский текст, перевод, передатчик, сборник и номер. Он стоит в своей
   рамке, чтобы ученик не спутал его с текстом изучаемой книги.
   Если удалите картинку из «Файлов», на сайте блок просто пропадёт; удалите и сам блок, иначе урок не сохранится.
2. **Обучение → Курсы → Создать.** Название, ступень, описание, затем **модули** — в каждый модуль добавьте уроки по порядку.
3. **Материалы → Статьи**, **Библиотека** (загрузите PDF), **Файлы**.
4. **Сайт → Настройки сайта** — тексты главной, «О сайте», город для времени намазов, а в блоке «Связаться с нами»: Telegram, почта, канал, ВКонтакте, YouTube, срок ответа и «Частые вопросы».
5. **Библиотека** — у книги укажите вид (матн, шарх…), ступень и, для шарха, «на какую книгу». Из этого сам строится «Путь изучения». Галочка «Опорная книга мазхаба» выводит книгу в отдельный блок. PDF загружайте только если его разрешено распространять; иначе добавьте ссылку «Читать онлайн».
6. **Статьи и вопросы** — у каждого материала выберите тип: «Статья» или «Разбор вопроса». Для разбора заполните «Вопрос» и «Краткий ответ», а ниже соберите подробный разбор из тех же блоков, что и текстовые уроки (арабский текст + перевод, пояснение, термины, пометки, рисунок).
7. **Ученики → Вопросы с сайта** — вопросы из формы обратной связи.
8. **Коран → Переводы сур → Создать.** Укажите номер суры и перетащите свой файл Word (.docx), затем «Сохранить».
   В файле каждый аят — отдельный абзац, начинается с номера: «1. Благословен Тот…» (как в «Коран 67.docx»);
   арабские абзацы и заголовки пропускаются, абзац «С именем Аллаха…» становится переводом басмалы. На сайте основной
   текст жирный, всё в [ ] и ( ) — обычным шрифтом. Если в файле не хватает аята или есть лишний, админка не сохранит
   перевод и напишет, каких аятов не хватает. Абзац перевода без номера (например, аят, разбитый на два абзаца) тоже
   ошибка: соедините его с аятом. Если номера стоят автоматическим списком Word, превратите список в обычный текст. Комментарий к аяту: откройте нужный «Аят» в списке «Аяты» и напишите
   его в поле «Комментарий» — у аята на сайте появится кнопка «Комментарий». Повторная загрузка файла обновляет
   переводы и не трогает комментарии. Арабский текст постоянный (мусхаф Медины), в админке его нет.
9. **Коран → Чтецы** — кто есть во вкладке «Слушать». «Ссылка на папку»: адрес, к которому дописывается номер суры
   (001.mp3 … 114.mp3), так подключены семь чтецов с mp3quran.net. «Свои файлы MP3»: добавьте «Запись суры» — номер
   и MP3; у сур без записи этого чтеца не будет. Порядок в списке — по полю «Порядок».
   Когда сура звучит, читаемый аят подсвечивается, а страница едет за чтецом. Это работает у чтецов с mp3quran.net,
   для которых там есть разметка аятов; у своих MP3 подсветки нет.

Галочка **«Опубликовано на сайте»** позволяет скрыть материал, не удаляя его.

**Видео:** загрузите ролик в Kinescope (или VK Видео / Rutube), скопируйте **ссылку для встраивания** (embed)
и вставьте в поле «Ссылка на видео». Например: `https://kinescope.io/embed/xxxxxxxx`.

## Размещение на хостинге

Нужны: **сервер или облачное приложение с Node.js 24** (или Docker), **база PostgreSQL**, домен.
Подойдёт российский облачный хостинг (например, Timeweb Cloud или Selectel).

### Переменные окружения

Скопируйте `.env.example` в `.env` (или задайте те же переменные в панели хостинга):

- `DATABASE_URL` — адрес базы PostgreSQL;
- `PAYLOAD_SECRET` — длинная случайная строка;
- `NEXT_PUBLIC_SERVER_URL` — адрес сайта, например `https://imam-ahmad.ru`;
- по желанию: `S3_*` (хранилище файлов) и `SMTP_*` (почта для смены пароля).

### Первый запуск

```bash
npm install
npm run migrate:create -- initial   # один раз: создаёт описание таблиц базы (src/migrations)
npm run migrate                     # создаёт таблицы в базе
npm run build
npm run start                       # сайт на порту 3000
npm run seed                        # по желанию: демо-курс из двух уроков
```

Файлы, созданные `migrate:create`, нужно сохранить в репозитории (папка `src/migrations`).
Дальше при каждом изменении структуры данных: `npm run migrate:create -- <название>` → `npm run migrate`.

Затем откройте `https://ваш-сайт/admin` и создайте **первого пользователя — он автоматически станет администратором**.
(Если регистрация включена, все, кто регистрируется на сайте позже, — ученики.)

### Docker

В проекте есть `Dockerfile`: `docker build -t academy .` → `docker run -p 3000:3000 --env-file .env academy`.
Если файлы хранятся на диске (без S3), подключите постоянный том к папке `/app/media`.

- [ ] Заменить демо-курс и тексты в квадратных скобках.
- [ ] Указать Telegram и почту в «Настройках сайта».

Перед **включением регистрации** дополнительно:

- [ ] Текст **политики конфиденциальности** (`src/app/(frontend)/privacy/page.tsx`) — подготовить с юристом (152-ФЗ).

- [ ] Почта (SMTP), чтобы работало «Забыли пароль?».
- [ ] После первой успешной сборки: `npx tsc --noEmit`, исправить ошибки типов и убрать
      `typescript.ignoreBuildErrors` из `next.config.ts`.
