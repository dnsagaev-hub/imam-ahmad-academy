# 030: «Вопрос» и «Ответ» в тексте книги — выделены (уровень А)

урок 3 по «аль-Масаиль аль-фикхийя»; после задачи 22 весь перевод жирный, и подписи слились с текстом).
Решение: в блоке «Текст книги» абзац, который начинается с «Вопрос N.» или «Ответ.», показывает эти слова отдельной

Данные не меняются: подпись находится по началу абзаца (`QaParagraph` в `src/components/text/LessonText.tsx`, класс `.tl-qa`).
