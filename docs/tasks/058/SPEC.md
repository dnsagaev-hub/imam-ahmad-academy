## Что сделано (только у дополнительных курсов; основной курс не меняется)
- Страница курса: «Программа курса» — один список «Урок 1 … Урок 15» без раскрывающихся модулей; в шапке курса нет
  «модулей: N» (`CourseProgram.tsx`, `courses/[slug]/page.tsx`).
- Урок: слева «Уроки курса» — все уроки курса (а не уроки модуля); в пути вверху нет «Модуль 1» (`LessonParts.tsx`,
  `lessons/[slug]/page.tsx`).
- Урок: нет раздела «Словарь урока» в начале; заголовок раздела объяснения — только название темы, без «Теория» и
  номера (`ArabicLesson.tsx`, параметр `plain`).
- Данные не меняются: в админке уроки по-прежнему стоят в модуле курса (поле «Модули» обязательно), ученику модуль не
  виден. Слова из словаря урока остаются в базе — в «Словаре курса» и подсказках они есть.
