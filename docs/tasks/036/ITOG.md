# 036: пункт «Уроки» в меню шапки (уровень А)

Задача: «Объединить вкладки в шапке сайта „Текстовые уроки“, „Аудиоуроки“, „Видеоуроки“ в одну вкладку „Уроки“,
наведя на неё, откроется три вкладки… А затем уже вкладки, которые есть у этих трёх вкладок, будут по стандарту»
(слова владельца 23.10.2026).
Решение: в `src/components/NavMenu.tsx` три пункта собраны в группу «Уроки» (своей страницы у неё нет).
Компьютер: наведение на «Уроки» — список из трёх разделов, наведение на раздел — справа его рубрики, нажатие на раздел
ведёт на его страницу, как раньше. Телефон: нажатие на «Уроки» раскрывает три раздела, стрелка у раздела — его рубрики.
Пункт «Уроки» подчёркнут, когда открыт любой из трёх разделов. Стили — в `styles.css` (блоки «Пункт „Уроки“»).
Страницы `/text`, `/audio`, `/video` и их рубрики не менялись; данные не меняются.
Почему уровень А: порядок и вид меню при тех же данных; поля коллекций и доступ не меняются.
Режим: одиночный. Ссылки: задача 36 в `TASKS.md`, ветка `claude/project-thread-7wwp1g`, базовая ревизия `2e508b4`.
