путь выбран в чате: озвучить словарь нейросетью, владелец прослушивает, неудачные слова заменяет своей записью в админке.

## Цель
Ученик на уроке арабского нажимает кнопку у слова в «Словаре урока» и слышит, как оно произносится.

## Границы
Входит:
- Кнопка «Послушать» (значок динамика) у каждого слова словаря урока: карточки имён и глаголов, «Особое слово», таблица служебных слов.
- Озвучка нейросетью всех слов уроков 1–8 (по огласованному тексту слова) один раз; файлы лежат в папке сайта
  `public/arabic/audio/` и попадают в Docker-образ и на хостинг вместе с кодом, база не нужна.
- Поле в админке у слова «Своя запись произношения» (аудиофайл). Если оно заполнено — играет запись владельца, а не нейросеть.
- Команда для озвучки новых уроков, которые добавит ИИ: озвучивает только слова без файла.
- Миграция (только новый столбец), проверка в CI: у слова урока есть кнопка, файл по ней отвечает 200.

Не входит:
- Озвучка предложений и текста урока, кнопка в плавающем словаре и подсказках (можно следующим шагом).
- Слова, которые владелец впишет в админке сам: для них — своя запись или просьба ИИ озвучить.

## Критерии приёмки
- К1: на уроках 1–8 у каждого слова словаря есть кнопка «Послушать»; нажатие проигрывает слово; повторное нажатие — заново.
- К2: если у слова в админке загружена своя запись — играет она.
- К3 (отрицательный): у слова без озвучки и без записи кнопки нет, страница не ломается.
- К4: на 390 кнопка не вызывает горизонтальной прокрутки, на 1440 не сдвигает карточку.
- К5: миграция без `DROP` в `up`; уроки и данные владельца сохраняются.

каждого из 189 слов проверено отдельно, неверные переозвучены и проверены ещё раз (все с огласовкой окончания: thalāthatun, barakatun). Это машинная проверка; на слух слова прослушивает владелец.
