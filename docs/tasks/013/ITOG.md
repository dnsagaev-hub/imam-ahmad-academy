# 013: Главная — арочная дверь и эмблема вместо узора (уровень А)

Задача: на главной в зелёном блоке убрать узор из звёзд. На компьютере над заголовком — арочная дверь, которая
распахивается при загрузке страницы; изнутри идёт свет и видна эмблема (подтекст владельца: «этот сайт открывает дверь
к знаниям»). На телефоне — большая полупрозрачная эмблема по центру за текстом (слова владельца 19.10.2026, выбор по
макетам в `/mnt/project-files/design-home/`: `dver-kompyuter.png`, `dver-animaciya.mp4`, `emblema-1-centr-telefon.png`).
Почему уровень А: меняется только вид одной страницы (стиль и картинка); данные, база, логика и другие страницы не затронуты
Режим: одиночный. Ссылки: задача 13 в `TASKS.md`, ветка `claude/project-thread-kx27wb`, базовая ревизия `3d7c351`
Источник: — (просьба владельца в чате)

## Входит и не входит
Входит:
- `src/app/(frontend)/page.tsx`: дверь (рамка, свет с эмблемой, две створки, отсвет) и эмблема-водяной знак;
- `src/components/Header.tsx`: свойство `plain` — зелёный блок без узора (передаёт только главная);
- `src/app/(frontend)/styles.css`: стили и анимация двери; при «уменьшить движение» в системе дверь сразу открыта;
  до 760 px вместо двери — эмблема за текстом и прежний орнамент;
- `public/brand/emblem-white.png`: белый силуэт эмблемы для водяного знака (сделан из `emblem.png`);
- `.github/workflows/ci.yml`: проверка, что на главной есть дверь и эмблема; снимок главной — через 3 с, когда дверь открыта.

Не входит:
- зелёные блоки «Мой прогресс» и «Личный кабинет» — узор там остаётся;
- текст заголовка и абзаца — по-прежнему из настроек в админке.

## Решения по ходу
- Дверь открывается при каждом открытии главной, один раз, и остаётся открытой (владелец выбрал «Открывается при загрузке»).
- Створки — по контуру арки (слова владельца 19.10.2026).
- Анимация створок задаётся полной записью `animation` на каждой створке: при сборке сжатие CSS превращало общую запись
  без имени анимации в `animation: none`, и на первом прогоне CI (`edf3669`) дверь осталась закрытой.
- На втором прогоне (`64b385a`) дверь на снимке всё ещё закрыта, хотя в браузере открыта: снимок во всю длину
  страницы (fullPage) в Chromium рисует анимацию в начальном положении. Проверено на статической копии сайта из
  `site-preview.zip`: снимок окна и снимок участка показывают открытую дверь, снимок во всю длину — закрытую;
  `getBoundingClientRect` створки через 3 с — ширина 2 px (открыта). В CI перед снимком главной конечное положение
  двери закрепляется обычными стилями.
