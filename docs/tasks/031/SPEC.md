# 31: Сведения о суре — кнопки над сурой

Статус: план (тексты пишет владелец — его выбор 22.10.2026), слито (22.10.2026, PR №24)
Уровень: В — новая коллекция в админке, это новые таблицы в базе и миграция (данные владельца в Docker-томах)
Режим: одиночный
Ссылки: задача 31 в `TASKS.md`, ветка `claude/project-thread-msh9ma`, базовая ревизия `1aaaed1`
Источник: слова владельца 22.10.2026 в треде о разделе «Коран»: в шапке суры — кнопки «Название суры», «Цели суры»,
«Тематика суры» и «Место ниспослания» (Мекка или Медина, какие аяты где ниспосланы); по нажатию — плавающее окно,
чтобы читающий получил общие сведения о суре перед чтением.

## Цель
Перед чтением суры ученик открывает кнопками в шапке короткие сведения о ней: смысл названия, цели, темы и где
она ниспослана.

## Границы
Входит:
- Новый раздел админки «Коран → Сведения о сурах»: номер суры и четыре текста с оформлением (жирный, списки, ссылки):
  «Название суры», «Цели суры», «Тематика суры», «Место ниспослания»; галочка «Опубликовано».
- На странице суры под названием — ряд кнопок; кнопка видна, только если её текст заполнен и запись опубликована.
  Нажатие открывает плавающее окно (как у комментария к аяту), закрывается крестиком, щелчком мимо окна и клавишей Esc.
- Миграция, которая только добавляет таблицы.
- Демо-запись в демо-наполнении (пометка «Пример»), чтобы CI проверял показ кнопок.

Не входит:
- Сами тексты о сурах. Их пишет владелец в админке (научный текст — по правилам из `AGENTS.md`).
- Изменение списка сур и деления на мекканские и мединские в данных сайта.

## Допущения и ответы
| Вопрос | Ответ или допущение | Источник | Блокирует? |

| Кто пишет тексты | Владелец в админке | Выбор владельца 22.10.2026 («Пишу сам в админке») | Нет |
| Отдельный раздел или в «Переводе суры» | Отдельный: сведения нужны и для сур без перевода | Допущение | Нет |
| Пустая кнопка | Не показывается | Допущение | Нет |

## Критерии приёмки
- К1: в админке в «Коран → Сведения о сурах» можно создать запись для суры: номер и четыре текста; вторую запись для
  той же суры создать нельзя.
- К2: на странице суры с опубликованной записью видны кнопки заполненных пунктов; нажатие открывает окно с заголовком
  пункта и текстом; окно закрывается крестиком, щелчком мимо и Esc.
- К3 (граница): у суры без записи, а также с неопубликованной записью, кнопок нет, страница выглядит как раньше.
- К4 (граница): на телефоне (390) кнопки переносятся на новую строку, окно помещается на экран, горизонтальной прокрутки нет.
- К5: миграция только добавляет таблицы (без `DROP`), данные владельца сохраняются.
