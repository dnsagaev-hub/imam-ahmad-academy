# 020: Пропорции картинки в свободном тексте статьи (уровень А)

Задача: владелец попросил статью «От первых уроков к глубокому изучению: четыре книги Ибн Кудамы по фикху» со
схемой в конце (слова владельца 20.10.2026). Текст статьи со ссылками на источники положен в поле «Свободный
текст» (в блоках ссылки не нажимаются), схема — картинка внутри этого текста. На тестовой копии картинка
растягивалась по высоте: у `<img>` из редактора есть атрибуты `width`/`height`, а общее правило `img` задаёт только
`max-width: 100%`, поэтому ширина сжималась, а высота оставалась исходной.
Почему уровень А: стиль, данные и поля коллекций не меняются.
Режим: одиночный. Ссылки: задача 20 в `TASKS.md`, ветка `claude/project-thread-c3ba70`, базовая ревизия `2f9fea1`.

## Входит и не входит
Входит: правило `.prose img` в `src/app/(frontend)/styles.css` — `height: auto` (пропорции), не шире 760px,
по центру, скруглённые углы. Касается картинок в поле «Свободный текст» статей.
Не входит: сама статья — её загружает в локальную базу владельца отдельный шаг после его одобрения (файлы
статьи — в папке проекта, в `main` не нужны).
