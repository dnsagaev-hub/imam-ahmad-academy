## Цель
Владелец в админке прикрепляет к уроку несколько аудиозаписей, у каждой своя подпись; ученик видит их списком на странице урока.

## Границы
Входит:
- Поле урока «Ещё аудио к уроку» (вкладка «Видео и аудио»): список строк «Подпись» + «Аудиофайл (MP3)», порядок можно менять перетаскиванием.
- Страница урока: если аудио больше одного — список, у каждой записи подпись, кнопка «Слушать», полоска «где остановились» и «Скачать MP3».
  Играет общий плеер внизу экрана, в нём видно «Урок: подпись».
- Поле доступно у любого урока (не только арабского) — так проще и ничего не ломает.

Не входит:
- Раздел «Аудиоуроки» (`/audio`) по-прежнему показывает урок по основному полю «Аудиофайл (MP3)».

## Критерии приёмки
- К1: в админке у урока можно добавить 2–3 аудио с подписями и сохранить.
- К2: на странице урока все аудио видны списком в том же порядке, каждое играет и скачивается.
- К3 (старые уроки): урок с одним «Аудиофайлом (MP3)» и без новых строк выглядит и работает как раньше; позиция прослушивания сохраняется.
- К4: на 390 нет горизонтальной прокрутки.
- К5: миграция только создаёт таблицу `lessons_audios`, без `DROP` в `up`.

## Решения исполнителя
- Файл в строке не обязателен на уровне базы (иначе удаление файла из «Медиа» падало бы), но админка не даст сохранить строку без файла.
  Строка без файла на сайте не показывается.
- Дата в имени миграции — сразу после таблицы слов арабского (как в задаче 51): миграции уроков 1–40 создают уроки через API Payload,
  а он уже читает новую таблицу. На базе владельца миграция выполнится как ещё не выполненная.

## Проверка
- Локальная база: миграции с нуля (все 80+) и поверх уже мигрированной базы — успешно; повторный `migrate:create` — «изменений схемы нет».
- Урок 1 арабского с тремя аудио: снимки 1440 и 390, горизонтальной прокрутки нет, кнопка запускает нужную запись в нижнем плеере.
