# 8: Уроки по книгам: дисциплина → книга → уроки; ссылка на уроки в карточке книги

Статус: черновик (ждёт ворот 1)
Уровень: В — новое поле в коллекции «Уроки» и миграция базы (данные владельца в Docker-томах)
Режим: одиночный
Ссылки: задача 8 в `TASKS.md`, ветка `claude/project-thread-8d03nh`, базовая ревизия `c73ceb6`
Источник: —

## Цель
В разделах «Аудиоуроки», «Видеоуроки» и «Текстовые уроки» ученик выбирает дисциплину, видит полку книг
(обложка и название), по которым есть уроки, открывает книгу и видит список её уроков с тестами и файлами.
На странице книги в библиотеке видно, что по ней есть уроки, и есть ссылки, ведущие прямо к ним.

## Границы
Входит:
- В уроке новое необязательное поле «Книга» (выбор книги из библиотеки).
- Если поле не заполнено, а урок входит в курс, книга берётся из курса («Учебники из библиотеки», первая книга).
- Три раздела: дисциплина → полка книг → страница уроков книги. Уроки без книги — блок «Другие уроки» под полкой.
- Страница книги в библиотеке: блок «Уроки по этой книге» со ссылками на аудио, видео и текстовые уроки (с числом).
- Миграция, которая только добавляет столбец.

Не входит:
- Изменение тестов, прохождения курсов и прогресса.
- Заполнение поля «Книга» в уже существующих уроках владельца (это делает владелец в админке; уроки курсов
  подхватят книгу курса сами).

## Критерии приёмки
- К1: `/audio?category=fiqh` показывает полку книг раздела «Фикх», у которых есть аудиоуроки: обложка и название.
- К2: нажатие на книгу открывает список её аудиоуроков (номер, название, длительность, отметка «тест», отметка «файлы»);
  то же для видео и текстовых уроков.
- К3: урок без книги и вне курса виден в блоке «Другие уроки» (не пропадает).
- К4: урок курса без заполненного поля «Книга» попадает к первой книге курса.
- К5: на странице книги библиотеки, по которой есть уроки, блок «Уроки по этой книге» со ссылками и числом уроков
  по видам; ссылка ведёт на страницу уроков этой книги в нужном разделе.
- К6 (отрицательный): у книги без уроков блока нет; книга без уроков не появляется на полке.
- К7 (граница): несуществующая книга в адресе — понятное сообщение «по этой книге уроков нет», не ошибка сервера;
  на телефоне (390) нет горизонтальной прокрутки.
- К8: миграция только добавляет столбец (`ADD COLUMN`, без `DROP`), данные уроков сохраняются; верные ответы тестов
  по-прежнему не уходят в браузер.
